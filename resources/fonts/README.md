# DejaVu fonts

DejaVu Sans, DejaVu Sans Bold and DejaVu Serif 2.37 are bundled for portable PDF/image authoring. Website rendering uses its existing system fonts and does not load these files.

Source: https://github.com/dejavu-fonts/dejavu-fonts/releases/tag/version_2_37

Unmodified files from `dejavu-fonts-ttf-2.37.zip`; license in `LICENSE`.
